# QAMap Support

QAMap is an early open-source project maintained through its public GitHub repository.

## Get Help

- Unexpected behavior or CLI failure: [open a bug report](https://github.com/IvoryCanvas/QAMap/issues/new?template=bug_report.yml)
- Missed flow, false positive, wrong evidence, or unusable draft: [open a QA miss report](https://github.com/IvoryCanvas/QAMap/issues/new?template=qa_miss.yml)
- Rule or capability proposal: [open a rule request](https://github.com/IvoryCanvas/QAMap/issues/new?template=rule_request.yml)
- Security vulnerability: follow [SECURITY.md](SECURITY.md) instead of opening a public issue

## Include In A Report

Provide:

- QAMap version and operating system
- the exact command and exit status
- the expected QA judgment and actual result
- a minimized, invented, domain-neutral reproduction when possible

Never publish private repository names, source code, credentials, personal data, customer data, or internal URLs. Replace them with a small public fixture that preserves the behavior.

## Support Scope

Maintainers triage reproducible defects and generalizable QA misses. QAMap does not provide a guaranteed response time, private product consulting, or support for unauthorized repository access.
