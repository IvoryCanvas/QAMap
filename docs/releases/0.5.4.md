# QAMap 0.5.4

This record describes the planned 0.5.4 release prepared on 2026-11-23. The date records preparation. The release preparation PR depends on QAMap #332, #333, #334, #335, #336, and #338 landing on `main`. npm publication, the GitHub release, and plugin directory submissions are separate steps.

## Plugin release notes

QAMap 0.5.4 surfaces more review evidence for changed guards, Python and AVA tests, in-place array updates, and competing writes while a callback is pending. The brief cites source and assertion lines so reviewers can verify each finding. The portable bundle requires QAMap CLI 0.5.4.

## Changes

- Ask evidence-linked review questions about changed exit guards, new error paths, and competing writes during deferred callbacks. Keep evidence and review questions separate from confirmed behavior.
- Recognize when replacing an array copy with an in-place insertion can change what a caller holding the original array sees.
- Surface relevant Python assertion lines when supported call and import evidence matches. Attribute AVA assertions, including asynchronous throw checks, to their owning tests.
- Use repository-relative paths for direct-package review and explain empty committed diffs when local edits exist.
- Correct Korean review terminology and emphasis. Use the currently published `v0.5.3` tag in the production GitHub Action example.
- Keep review-host dry-run and measurement output directories separate. Require explicit channels and a reviewed plan digest for release metadata changes.

## Compatibility and limits

The CLI and v1 report contracts remain compatible. Review questions identify source patterns and candidate checks. The calling host interprets the evidence, and the CLI reports tests as unexecuted during static review. New host token usage and model review quality remain unmeasured.

The portable npm and OpenAI metadata are prepared together. The native Claude directory keeps its own plugin version and is released through its separate review process. Its documented CLI pin follows the prepared package version.

[QAMap #317](https://github.com/IvoryCanvas/QAMap/issues/317) remains open for root-cause evidence. The existing coverage concurrency bound is retained.
